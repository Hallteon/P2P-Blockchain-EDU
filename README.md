# P2P-Blockchain-EDU
Учебное настольное приложение на C++/Qt, демонстрирующее базовые принципы:  - объектно-ориентированного проектирования; - построения простого блокчейна; - peer-to-peer взаимодействия между узлами; - обмена сообщениями по сети в формате JSON; - асинхронного майнинга в отдельном потоке.

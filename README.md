# P2P-Blockchain-EDU ⛓📦

Учебное настольное (Desktop) приложение на **C++/Qt**, наглядно демонстрирующее базовые принципы построения децентрализованных систем, криптографии и объектно-ориентированного проектирования.

## 🚀 Ключевые особенности и демонстрация

* **Простая архитектура блокчейна:** Реализация цепочки блоков, валидации транзакций, вычисления хэшей и защиты от изменения данных.
* **Peer-to-Peer (P2P) сеть:** Организация прямого взаимодействия между запущенными узлами (нодами) приложения без участия центрального сервера.
* **Обмен сообщениями в JSON:** Структурированный сетевой обмен данными, транзакциями и блоками через сериализацию в формат JSON.
* **Асинхронный майнинг:** Вынос процесса вычисления хэшей (Proof-of-Work) в отдельный изолированный рабочий поток (Multithreading) для предотвращения зависания графического интерфейса.
* **Интерфейс на Qt:** Удобная визуализация текущего состояния блокчейна, списка подключенных пиров и логов сети.

## 🛠 Технологический стек

* **Язык разработки:** C++ (стандарт C++17 и выше)
* **Фреймворк UI и сети:** Qt5 / Qt6 (QtCore, QtNetwork, QtWidgets)
* **Система сборки:** CMake

## 🛠 Сборка и запуск приложения

### Требования
* Компилятор с поддержкой C++17 (GCC, Clang или MSVC)
* Установленный фреймворк **Qt (5.15+ или 6.x)**
* Система сборки **CMake (3.16+)**

### Инструкция по сборке

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd P2P-Blockchain-EDU
   ```

2. Создайте каталог сборки и перейдите в него:
   ```bash
   mkdir build && cd build
   ```

3. Сконфигурируйте и соберите проект с помощью CMake:
   ```bash
   cmake ..
   cmake --build .
   ```

4. Запустите исполняемый файл приложения из папки `build`. Для тестирования P2P-функций вы можете запустить несколько копий приложения на одном компьютере, указав разные сетевые порты в интерфейсе.
